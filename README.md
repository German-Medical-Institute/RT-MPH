# RT-MPH

**Radiotherapy Medical Physics**

![Python](https://img.shields.io/badge/Python-3.x-3776AB?logo=python\&logoColor=white)

This repository contains scripts, tools, and utilities developed to support and improve the workflow of the Medical Physics department.

## Purpose

The goal of this repository is to provide a central location for tools that help streamline routine tasks, improve efficiency, reduce repetitive work, and support the clinical and technical workflows of the department.

The repository may include scripts for:

* Treatment planning and treatment planning system workflows
* Data processing and analysis
* Quality assurance (QA)
* Clinical workflow automation
* Machine and treatment-related tasks
* Reporting and documentation
* File and data management
* Other departmental utilities

## RayStation Scripts

The `RayStation Scripts` folder contains Python scripts developed to assist with workflows within RayStation treatment planning system.

See the [RayStation Scripts](./RayStation%20Scripts/) folder for more information and documentation.

## Development

Scripts in this repository are developed to support departmental workflows. Before using a script in a clinical workflow, its functionality should be reviewed and appropriately validated for the intended use.

Changes and new tools should be documented where appropriate to facilitate maintenance and future development.
